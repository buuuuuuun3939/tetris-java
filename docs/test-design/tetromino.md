# ミノ形状・回転テスト設計

## 対象

- 要件対象: `Tetromino`
- テストクラス: `TetrominoTest`
- テストソース: `src/test/java/TetrominoTest.java`
- 状態: 4ケースを実装済み。テストメソッドに `@Disabled` は付いていない。

## 要件

| 要件ID | 要件 |
|---|---|
| TET-REQ-01 | 各 `TetrominoType` は定義された初期形状と色を持つ。 |
| TET-REQ-02 | `rotate()` は形状を時計回りに90度回転する。 |
| TET-REQ-03 | `getRotatedShape()` は回転後形状を返すが、現在形状は変更しない。 |
| TET-REQ-04 | 4回回転すると初期形状に戻る。 |

## 初期形状・色の期待値

形状の `1` はミノのブロック、`0` は空きマスです。配列の各内側配列が盤面の1行に対応します。

| 種類 | 初期形状 | 色 |
|---|---|---|
| I | `[[1,1,1,1]]` | `Color.CYAN` |
| O | `[[1,1],[1,1]]` | `Color.YELLOW` |
| T | `[[0,1,0],[1,1,1]]` | `Color.MAGENTA` |
| S | `[[0,1,1],[1,1,0]]` | `Color.GREEN` |
| Z | `[[1,1,0],[0,1,1]]` | `Color.RED` |
| J | `[[1,0,0],[1,1,1]]` | `Color.BLUE` |
| L | `[[0,0,1],[1,1,1]]` | `Color.ORANGE` |

## テストケース

| ケースID | 前提条件 | 操作 | 期待結果 | 優先度 | 状態 |
|---|---|---|---|---|---|
| TET-001 | `TetrominoType` の各値 | 各値で `Tetromino` を作成し、`getShape()` と `getColor()` を取得する | 各行の列数と値、および色が上表の期待値と一致する | P1 | 実装済み・有効 |
| TET-002 | 各種類の初期形状 | `getRotatedShape()` の戻り値を取得する | 各行の列数と値が下表の時計回り90度回転後の形状と一致する | P1 | 実装済み・有効 |
| TET-003 | 各種類の初期形状 | 初期形状を保存し、`rotate()` を4回呼び出して最終形状を取得する | 行数と各行の値が初期形状と一致する | P2 | 実装済み・有効 |
| TET-004 | 各種類の初期形状 | 初期形状を行ごとにコピーし、`getRotatedShape()` 呼び出し後に現在形状を再取得する | 行数と各行の値が呼び出し前のコピーと一致する | P1 | 実装済み・有効 |

## テストメソッドとの対応

| ケースID | テストメソッド |
|---|---|
| TET-001 | `eachTypeHasExpectedInitialShapeAndColor` |
| TET-002 | `eachTypeReturnsExpectedClockwiseRotatedShape` |
| TET-003 | `fourRotationsRestoreInitialShape` |
| TET-004 | `gettingRotatedShapeDoesNotChangeCurrentShape` |

### TET-002: 時計回り90度回転後の期待値

| 種類 | 期待する形状 |
|---|---|
| I | `[[1],[1],[1],[1]]` |
| O | `[[1,1],[1,1]]` |
| T | `[[1,0],[1,1],[1,0]]` |
| S | `[[1,0],[1,1],[0,1]]` |
| Z | `[[0,1],[1,1],[1,0]]` |
| J | `[[1,1],[1,0],[1,0]]` |
| L | `[[1,0],[1,0],[1,1]]` |

## 実装時の注意

- 行列の内容は要素ごとに比較します。Javaの二次元配列に対する通常の `assertEquals` だけでは内容比較になりません。
- 各種類の初期形状・色と回転後形状は、期待値をこの設計書の表に固定します。テスト側で本体と同じ計算を再実装して期待値を作らないようにします。
- TET-001 と TET-002 は、期待値の各行について列数と値を比較します。現状のテストでは外側配列の行数を独立には比較していないため、余分な行の検出も必要であれば、行数の `assertEquals` を追加します。
- TET-003 は回転前後の行数を比較してから、各行の値を比較します。初期形状は `getShape()` の戻り値を参照しているため、初期形状を別配列にコピーして保存する形にすると、テストの意図がより明確になります。
- TET-004 は呼び出し前の各行をコピーして保持し、呼び出し後の現在形状と行数・各行の値を比較します。これにより、取得前の形状配列が変更されても比較元は変化しません。
- TET-004 は現在形状が変わらないことを検証します。回転後形状の値はTET-002で検証します。
