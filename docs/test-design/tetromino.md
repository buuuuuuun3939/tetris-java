# ミノ形状・回転テスト設計

## 対象

- 要件対象: `Tetromino`
- テストクラス: `TetrominoTest`
- テストソース: `src/test/java/TetrominoTest.java`
- 状態: 4ケースのメソッド骨組み作成済み。検証処理は未実装で、各メソッドは `@Disabled`。

## 要件

| 要件ID | 要件 |
|---|---|
| TET-REQ-01 | 各 `TetrominoType` は定義された初期形状と色を持つ。 |
| TET-REQ-02 | `rotate()` は形状を時計回りに90度回転する。 |
| TET-REQ-03 | `getRotatedShape()` は回転後形状を返すが、現在形状は変更しない。 |
| TET-REQ-04 | 4回回転すると初期形状に戻る。 |

## 初期形状・色の期待値

形状の `1` はミノのブロック、`0` は空きマスです。配列の各内側配列が盤面の1行に対応します。

| 種類 | 初期形状 | 色 |
|---|---|---|
| I | `[[1,1,1,1]]` | `Color.CYAN` |
| O | `[[1,1],[1,1]]` | `Color.YELLOW` |
| T | `[[0,1,0],[1,1,1]]` | `Color.MAGENTA` |
| S | `[[0,1,1],[1,1,0]]` | `Color.GREEN` |
| Z | `[[1,1,0],[0,1,1]]` | `Color.RED` |
| J | `[[1,0,0],[1,1,1]]` | `Color.BLUE` |
| L | `[[0,0,1],[1,1,1]]` | `Color.ORANGE` |

## テストケース

| ケースID | 前提条件 | 操作 | 期待結果 | 優先度 | 状態 |
|---|---|---|---|---|---|
| TET-001 | `TetrominoType` の各値 | 各値で `Tetromino` を作成する | `getShape()` と `getColor()` が上表の期待値と一致する | P1 | 骨組み作成済み・未実装 |
| TET-002 | 各種類の初期形状 | `getRotatedShape()` の戻り値を確認する | 戻り値が下表の時計回り90度回転後の形状と一致する | P1 | 骨組み作成済み・未実装 |
| TET-003 | 各種類の初期形状 | `rotate()` を4回呼び出す | 最終形状がTET-001の初期形状と一致する | P2 | 骨組み作成済み・未実装 |
| TET-004 | 任意の種類の初期形状 | 回転後形状を取得し、現在形状も再取得する | 戻り値は回転後形状、現在形状は呼び出し前と一致する | P1 | 骨組み作成済み・未実装 |

### TET-002: 時計回り90度回転後の期待値

| 種類 | 期待する形状 |
|---|---|
| I | `[[1],[1],[1],[1]]` |
| O | `[[1,1],[1,1]]` |
| T | `[[1,0],[1,1],[1,0]]` |
| S | `[[1,0],[1,1],[0,1]]` |
| Z | `[[0,1],[1,1],[1,0]]` |
| J | `[[1,1],[1,0],[1,0]]` |
| L | `[[1,0],[1,0],[1,1]]` |

## 実装時の注意

- 行列の内容は要素ごとに比較します。Javaの二次元配列に対する通常の `assertEquals` だけでは内容比較になりません。
- 各種類の初期形状・色と回転後形状は、期待値をこの設計書の表に固定します。テスト側で本体と同じ計算を再実装して期待値を作らないようにします。
- `getRotatedShape()` の非変更性は、呼び出し前に保存した初期形状との比較で確認します。
